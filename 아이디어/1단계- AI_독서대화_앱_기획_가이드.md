## 1. 앱 컨셉과 핵심 가치

### 1.1 앱 정의

```mermaid
mindmap
  root((리딩클루<br/>ReadingClue))
    읽기 Read
      ISBN 스캔으로 책 등록
      읽기 진도 관리
      하이라이트 메모
    대화 Talk
      AI 독서 대화
      소크라테스식 질문
      맥락 기반 토론
    공유 Share
      관점 교환
      독서 모임 운영
      멤버 간 토론
    기록 Record
      대화 아카이브
      성장 포트폴리오
      인사이트 타임라인
```

### 1.2 한 줄 정의

> **리딩클루 = 독서 기록 + AI 대화 파트너 + 독서 모임 커뮤니티 + 관점 아카이브**
>
> ※ 전자책 리더가 아닌, **"읽은 후의 사고 확장"**에 특화된 독서 컴패니언 앱

### 1.3 핵심 가치

| 핵심 가치 | 설명 | 기존 앱과의 차이 |
|-----------|------|----------------|
| **함께 읽는 경험** | 혼자가 아닌 모임 기반 독서 | 기존: 개인 독서 기록 중심 |
| **AI 대화 파트너** | 책 내용에 대해 AI와 깊이 있는 대화 | 기존: 단순 요약/추천만 제공 |
| **관점의 교차** | 같은 책, 다른 시각을 발견 | 기존: 별점/리뷰만 있음 |
| **성장 기록** | 사고의 변화를 시간순 추적 | 기존: 읽은 책 목록만 관리 |
| **소크라테스식 토론** | 답이 아닌 질문으로 생각을 확장 | 기존: 정보 전달 위주 |

| 기록 안 남음 | 모든 대화와 인사이트 자동 저장 | 나의 사고 성장 추적 가능 |
| AI 활용법 모름 | 독서 맥락에 최적화된 AI 대화 | AI를 사고 확장 도구로 활용 |

## 3. 기존 독서 앱과의 차별점

### 3.1 경쟁 앱 비교 분석

| 기능 | 밀리의 서재 | 리디북스 | 북클럽 | 트레바리 | **리딩클루** |
|------|-----------|---------|--------|---------|------------|
| 핵심 가치 | 전자책 구독 | 전자책 구독 | 소셜 독서 | 오프라인 모임 | **AI 독서 대화** |
| 독서 기록 | △ | △ | O | △ | **O (심화)** |
| AI 대화 | X | X | X | X | **O (핵심)** |
| 독서 모임 | X | X | △ | O (오프라인) | **O (온·오프)** |
| 관점 공유 | X | X | △ | O (오프라인) | **O (시스템화)** |
| 토론 기록 | X | X | X | X | **O (자동)** |
| 성장 추적 | X | X | △ | X | **O (AI 분석)** |
| 회원 모집 | X | X | X | O (플랫폼) | **O (인앱)** |
| 가격 | 월 9,900원 | 월 7,900원 | 무료 | 회당 2~5만원 | **프리미엄** |

> **참고**: 리딩클루는 전자책 제공 플랫폼이 아닙니다. 전자책/오디오북은 기존 서비스(밀리의 서재, 리디북스 등)를 이용하고, 리딩클루는 **"읽은 후의 경험"** — 대화, 토론, 관점 공유, 성장 추적에 집중합니다. 책은 종이책이든 전자책이든 어디서든 읽고, 리딩클루에서 생각을 확장합니다.

### 3.2 포지셔닝 맵

| 앱 이름 | 개인/커뮤니티 | 콘텐츠 소비/사고 확장 | 포지셔닝 |
|---------|---------------|----------------------|----------|

| 리디북스 | 개인 중심 | 콘텐츠 소비 | 전자책 구독 서비스 |
| 북클럽 | 중간 | 중간 | 소셜 독서 |
| 트레바리 | 커뮤니티 중심 | 사고 확장 | 학습 도구 |

**포지셔닝 요약**:
- **X축 (개인 ← → 커뮤니티)**: 리딩클루는 커뮤니티 중심 (0.8)
- **Y축 (콘텐츠 소비 ← → 사고 확장)**: 리딩클루는 사고 확장 중심 (0.85)
- **결론**: 리딩클루는 "커뮤니티 기반 사고 확장" 영역에서 독보적 위치

### 4.3 모임 생성 ~ 운영 흐름

```mermaid
sequenceDiagram
    actor 모임장
    participant 앱 as 리딩클루 앱
    participant AI as AI 어시스턴트
    actor 멤버
    
    모임장->>앱: 모임 생성
    앱->>AI: 도서 추천 요청
    AI-->>앱: 주제별 추천 도서 목록
    모임장->>앱: 도서 선정 + 일정 설정
    앱-->>앱: 모집 공고 자동 생성
    
    멤버->>앱: 모임 검색 & 가입 신청
    모임장->>앱: 가입 승인
    앱-->>멤버: 환영 + 첫 주 안내
    
    loop 매주 반복
        멤버->>앱: 개인 독서 (진도 기록)
        멤버->>AI: AI와 책 내용 대화
        AI-->>멤버: 질문 & 관점 제시
        멤버->>앱: 인사이트 기록
        
        Note over 모임장,멤버: 모임일
        모임장->>앱: 토론 세션 시작
        멤버->>앱: 관점 공유
        앱->>AI: 토론 포인트 생성
        AI-->>앱: 핵심 질문 & 관점 정리
        앱-->>멤버: 토론 기록 저장
    end
    
    앱-->>멤버: 성장 리포트 제공
```

## 5. AI 독서 대화 시스템

### 5.1 AI 대화의 3가지 모드

```mermaid
graph LR
    subgraph "AI 대화 모드"
        A[탐구 모드<br/>Explore] --> A1[소크라테스식 질문<br/>왜? 정말? 다르게 보면?]
        B[토론 모드<br/>Debate] --> B1[반대 관점 제시<br/>논증 구조 분석<br/>비판적 사고 촉진]
        C[정리 모드<br/>Organize] --> C1[핵심 요약<br/>인사이트 정리<br/>연결 고리 발견]
    end
    
    style A fill:#FF6B6B,color:#fff
    style B fill:#4ECDC4,color:#fff
    style C fill:#45B7D1,color:#fff
```

### 5.2 AI 대화 상세 기능

| 기능 | 설명 | 예시 |
|------|------|------|
| **맥락 인식 대화** | 현재 읽고 있는 책의 내용을 AI가 이해하고 대화 | "3장에서 저자가 말한 '공정'의 의미가 뭘까요?" |
| **소크라테스 질문** | 답을 주지 않고 질문으로 사고를 확장 | "그렇다면 '정의'는 누구의 관점에서 정의되는 걸까요?" |
| **다각적 관점 제시** | 하나의 주제에 대해 여러 관점을 보여줌 | "이 주제를 경제학자, 철학자, 사회학자는 어떻게 볼까요?" |
| **반대 논증** | 사용자의 의견에 건설적 반론을 제시 | "좋은 관점입니다. 하지만 반대 입장에서 보면..." |
| **연결 짓기** | 다른 책, 개념, 현실 사례와 연결 | "이 개념은 카뮈의 '이방인'에서도 나타나는데요..." |
| **대화 요약** | 대화의 핵심 인사이트를 자동 정리 | 대화 후 "오늘의 핵심 인사이트 3가지" 제공 |

### 5.3 AI 대화 흐름 예시

```mermaid
sequenceDiagram
    actor 사용자
    participant AI as AI 파트너
    participant 시스템 as 시스템
    
    사용자->>시스템: 책 "정의란 무엇인가" 3장 읽기 완료
    시스템->>AI: 독서 진도 + 사용자 메모 전달

    사용자->>AI: "소수의 희생이 정당화될 때요"
    AI-->>사용자: "트롤리 딜레마를 생각해보면,<br/>5명을 살리기 위해 1명을 희생하는 것은<br/>공리주의적으로 옳지만,<br/>칸트의 입장에서는 어떨까요?"

    AI-->>사용자: "정확합니다! 그렇다면 현실에서<br/>이 두 관점이 충돌하는 사례를 떠올려 볼까요?<br/>예를 들어, 코로나 시기의 방역 정책은<br/>어떤 윤리 체계에 가까웠을까요?"

    시스템-->>사용자: 📝 오늘의 인사이트 정리<br/>1. 공리주의의 한계 인식<br/>2. 칸트 윤리학과의 대비<br/>3. 현실 적용 사례 연결

    현우->>앱: 토론 가이드 수정 후 멤버에게 공유
    앱-->>멤버: 토론 전 준비 질문 알림
    
    Note over 현우,멤버: Step 4 - 성과 관리
    AI-->>현우: 월간 모임 활동 리포트 생성
    앱-->>현우: 멤버별 참여도, 성장 추이 대시보드
    현우->>앱: 우수 멤버 뱃지 부여
```

**모임장 대시보드 핵심 기능**:

| 기능 | 설명 | AI Agent 지원 |
|------|------|-------------|
| **멤버 진도 현황** | 전체 멤버의 읽기 진도를 한눈에 | 진도 부진 멤버에게 자동 독려 메시지 |
| **토론 가이드 생성** | 이번 주 토론 주제와 질문 목록 | AI가 책 내용 기반 토론 가이드 초안 생성 |
| **관점 분석 대시보드** | 멤버들의 관점 분포 시각화 | 의견 대립 포인트 자동 추출 |
| **참여도 히트맵** | 일별/주별 멤버 활동량 시각화 | 참여 저조 시 모임장에게 알림 |
| **모임 성과 리포트** | 월간/분기 모임 활동 요약 | AI가 자동 생성, PDF 내보내기 가능 |

| 인터랙션 | 패턴 | 설명 |
|----------|------|------|

| **진도 업데이트** | 슬라이더 드래그 또는 페이지 번호 입력 | 진도 변경 시 AI가 해당 부분 관련 질문 제안 |
| **AI 대화 시작** | 책 선택 → 모드 선택 → 대화 시작 | 이전 대화 이어하기 옵션 제공 |
| **인사이트 저장** | AI 대화 중 롱프레스 → 인사이트 저장 | 관련 구절 자동 태깅 |
| **관점 공유** | 인사이트 카드 → 공유 버튼 → 모임 선택 | 해시태그 자동 제안 |
| **토론 참여** | 알림 탭 → 토론방 입장 → 발언 | 발언 타이머, 순서 관리 AI |
| **Pull to Refresh** | 아래로 당기기 → 새 데이터 로드 | 홈, 서재, 모임 탭 공통 |
| **스와이프 액션** | 책 카드 좌 스와이프 → 빠른 액션 | 삭제, 완독 처리, 모임에 추천 |
