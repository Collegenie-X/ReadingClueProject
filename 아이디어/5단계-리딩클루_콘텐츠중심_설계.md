## 1. 콘텐츠 퍼스트 원칙

### 1.1 리딩클루의 콘텐츠 철학

```mermaid
mindmap
  root((리딩클루<br/>콘텐츠 철학))
    핵심 가치
      읽는 즐거움을 되찾다
      생각하는 힘을 기르다
      대화로 세상을 넓히다
      기록으로 성장을 남기다
    콘텐츠 원칙
      20분이면 충분하다
      정답은 없고 관점만 있다
      혼자보다 함께가 깊다
      AI는 돕되 주도하지 않는다
    차별점
      한국 독서 토론 학원의 온라인화
      점진적 몰입 시간 설계
      투 트랙 자율+공식 운영
      건전한 토론 문화 시스템
```

### 1.2 왜 콘텐츠가 먼저인가?

| 순서 | 항목 | 이유 |
|:---:|------|------|
| **1** | 콘텐츠 품질 | 좋은 콘텐츠가 있어야 사람이 모인다 |
| **2** | 커뮤니티 형성 | 콘텐츠로 모인 사람들이 문화를 만든다 |
| **3** | 자발적 확산 | 좋은 경험은 입소문으로 퍼진다 |
| **4** | 가격 정책 | 가치가 증명된 후에 비로소 의미 있다 |

> **"가격 먼저 정하면 '싸니까 써볼까'가 되고, 콘텐츠 먼저 만들면 '좋으니까 계속 쓰고 싶다'가 된다."**

## 2. 3트랙 운영 구조

### 2.1 핵심 철학: "기본을 알면, 모임이 살아난다"

> **"마구마구 모임을 만들어도 좋다. 하지만 기본을 알고 시작하면, 그 모임은 10배 더 깊어진다."**

독서 토론은 누구나 시작할 수 있지만, **잘** 하려면 기본이 필요합니다.
리딩클루는 "학습 → 외부(자유 모임) → 내부(공식 프로그램)" 3트랙으로,
**기본을 알려주고 → 자유롭게 모이게 하고 → 체계적으로 성장하게** 합니다.

### 2.2 3트랙 전체 구조도

```mermaid
graph TD
    subgraph "리딩클루 3트랙 콘텐츠 플랫폼"
        direction TB
        C["Track C: 학습 콘텐츠<br/>📚 독서토론 길라잡이<br/>'기본을 알면 모임이 달라진다'"]
        A["Track A: 외부 콘텐츠<br/>🌍 자유로운 모임 주선<br/>'마구마구 모여라!'"]
        B["Track B: 내부 콘텐츠<br/>🎓 AI 공식 프로그램<br/>'체계적으로 깊어진다'"]
    end

    C -->|"기본 배운 후"| A
    C -->|"기본 배운 후"| B
    A -->|"더 깊이 원하면"| B
    B -->|"졸업 후 자기 모임"| A

    C --> C1["독서토론 진행법 미니강의"]
    C --> C2["질문하는 법, 경청하는 법"]
    C --> C3["토론 유형별 가이드<br/>하브루타/디베이트/세미나"]
    C --> C4["학년별 교사 지시서 공개"]

    A --> A1["누구나 모임 만들기"]
    A --> A2["자유로운 책 + 주제"]
    A --> A3["AI MC 보조 + 매칭"]
    A --> A4["외부 강사/학원 연계"]

    B --> B1["검증된 36주 커리큘럼"]
    B --> B2["AI MC 주도 풀패키지"]
    B --> B3["초등/중등/고등/일반 과정"]
    B --> B4["포트폴리오 + 성장 기록"]

    style C fill:#45B7D1,color:#fff
    style A fill:#4ECDC4,color:#fff
    style B fill:#FF6B6B,color:#fff
```

### 2.3 3트랙 사용자 여정 (Journey)

```mermaid
flowchart LR
    A["가입"] --> B["Track C: 길라잡이<br/>━━━━━━━━━<br/>독서토론이 뭔지 배우기<br/>5~10분 미니강의 3편<br/>'이제 기본은 알았다!'"]
    B --> C{"어떻게 할까?"}
    C -->|"내가 만들 래!"| D["Track A: 외부<br/>━━━━━━━━━<br/>자유 모임 생성<br/>책·주제·시간 자유<br/>마구마구 모여라!"]
    C -->|"체계적으로!"| E["Track B: 내부<br/>━━━━━━━━━<br/>공식 프로그램 참여<br/>AI MC 주도<br/>36주 커리큘럼"]
    D --> F["경험 쌓임"]
    E --> F
    F --> G["Track C: 심화 학습<br/>━━━━━━━━━<br/>디베이트 진행법<br/>세미나 운영법<br/>글쓰기 첨삭법"]
    G --> H["더 좋은 모임 운영<br/>or 다음 레벨 참여"]
```

### 2.4 3트랙 비교표

| 항목 | Track C: 학습 (길라잡이) | Track A: 외부 (자유 모임) | Track B: 내부 (공식 프로그램) |
|------|:---:|:---:|:---:|
| **성격** | **배움** — 기본기 습득 | **실전** — 자유로운 실행 | **체계** — 전문적 프로그램 |
| **비유** | 운전면허 학원 | 자유 드라이브 | F1 레이싱 아카데미 |
| **대상** | 모든 사용자 (특히 입문) | 경험자, 모임장 | 체계적 성장 원하는 사용자 |
| **콘텐츠** | 미니강의, 가이드, 튜토리얼 | 모임 도구, AI 보조 | 36주 커리큘럼, AI MC 주도 |
| **시간** | 자율 (5~15분씩) | 자유 설정 (20분~) | 체계적 확장 (20→90분) |
| **비용** | **무료** (전원 접근) | 기본 무료 / 프리미엄 | 구독 or 패키지 |
| **AI 역할** | 학습 도우미, 퀴즈 | 보조 MC, 질문 추천 | 주도 MC, 풀 패키지 |
| **결과물** | 수료증, 기본 뱃지 | 자유 형식 기록 | 포트폴리오, 성장 기록 |
| **핵심 가치** | "알고 하면 다르다" | "자유롭게 모여라" | "깊이 있게 성장하라" |

## 3. 20분에서 시작하는 세션 설계

### 3.1 점진적 시간 확장 철학

> **"처음부터 90분은 부담. 20분이면 누구나 할 수 있다."**

```mermaid
graph LR
    A["Step 1<br/>20분<br/>맛보기"] --> B["Step 2<br/>30분<br/>익숙해지기"]
    B --> C["Step 3<br/>40분<br/>깊어지기"]
    C --> D["Step 4<br/>50분<br/>몰입하기"]
    D --> E["Step 5<br/>60분<br/>본격 토론"]
    E --> F["Step 6+<br/>70~90분<br/>심화 토론"]

    style A fill:#90EE90,color:#333
    style B fill:#7CD17C,color:#333
    style C fill:#FFD700,color:#333
    style D fill:#FFA500,color:#fff
    style E fill:#FF6B6B,color:#fff
    style F fill:#CC3333,color:#fff
```

### 3.2 시간 단계별 설계

| 단계 | 시간 | 회차 | 세션 구성 | 목표 |
|:---:|:---:|:---:|------|------|
| **Step 1** | 20분 | 1~2회차 | 자기소개 5분 + 한 줄 감상 10분 + 마무리 5분 | "말해봤더니 괜찮네" |
| **Step 2** | 30분 | 3~4회차 | 체크인 5분 + 감상 공유 15분 + 정리 10분 | "다른 사람 생각이 다르구나" |
| **Step 3** | 40분 | 5~6회차 | 체크인 5분 + 주제 토론 25분 + 정리 10분 | "내 생각을 말할 수 있다" |
| **Step 4** | 50분 | 7~8회차 | 체크인 5분 + 토론 30분 + 성찰 15분 | "깊이 있는 대화가 가능하다" |
| **Step 5** | 60분 | 9~12회차 | 체크인 5분 + 토론 40분 + 성찰 15분 | "본격적인 비판적 사고" |
| **Step 6** | 70분+ | 13회차~ | 체크인 5분 + 심화 토론 50분+ + 성찰 15분 | "전문적인 독서 토론" |

### 3.3 대상별 시간 적용

| 대상 | 시작 시간 | 최대 시간 | 확장 속도 | 비고 |
|:---:|:---:|:---:|:---:|------|
| **초등 (4~6)** | 20분 | 40분 | 2회마다 +5분 | 40분 넘기지 않음 |
| **중등** | 20분 | 60분 | 2회마다 +10분 | 60분이 기본 목표 |
| **고등** | 30분 | 70분 | 2회마다 +10분 | 논술 연계 시 80분 |
| **일반** | 30분 | 90분 | 2회마다 +10분 | 자율 조절 가능 |

## 4. 단계별 세션 구성표

### 4.1 Step 1: 20분 세션 (맛보기)

```mermaid
sequenceDiagram
    participant 멤버 as 멤버들
    participant AI as AI MC

    Note over 멤버,AI: === 오프닝 (0~5분) ===
    AI->>멤버: "안녕하세요! 오늘 읽은 책 한 줄로 소개해주세요"
    멤버->>AI: 각자 한 줄 소개 (1인 30초)

    Note over 멤버,AI: === 감상 나눔 (5~15분) ===
    AI->>멤버: "가장 인상 깊었던 장면이나 문장은?"
    멤버->>AI: 자유 발언 (AI가 순서 안내)
    AI->>멤버: "○○님 의견에 공감하는 분?"

    Note over 멤버,AI: === 마무리 (15~20분) ===
    AI->>멤버: "오늘 한 마디로 정리하면?"
    멤버->>AI: 각자 한 줄 성찰
    AI->>멤버: "다음 시간에 만나요! 읽기 범위는..."
```

### 4.2 Step 3: 40분 세션 (깊어지기)

```mermaid
sequenceDiagram
    participant 멤버 as 멤버들
    participant AI as AI MC

    Note over 멤버,AI: === 체크인 (0~5분) ===
    AI->>멤버: "이번 주 읽으면서 가장 궁금했던 점은?"

    Note over 멤버,AI: === 주제 토론 (5~30분) ===
    AI->>멤버: 질문 1 — 이해 확인 (쉬움)
    멤버->>AI: 자유 발언
    AI->>멤버: 질문 2 — 관점 비교 (중간)
    멤버->>AI: 의견 교환
    AI->>멤버: "반대로 생각해보면?"
    멤버->>AI: 반론 시도

    Note over 멤버,AI: === 정리 + 성찰 (30~40분) ===
    AI->>멤버: "오늘 나온 관점을 정리하면..."
    AI->>멤버: "다음 주까지 생각해볼 질문 하나!"
```

### 4.3 Step 5: 60분 세션 (본격 토론)

```mermaid
sequenceDiagram
    participant 멤버 as 멤버들
    participant AI as AI MC

    Note over 멤버,AI: === 체크인 (0~5분) ===
    AI->>멤버: "지난주 성찰 질문, 생각해보셨나요?"

    Note over 멤버,AI: === 토론 1: 이해 (5~20분) ===
    AI->>멤버: 질문 1 — 핵심 이해 확인
    멤버->>AI: 발언 + 후속 질문

    Note over 멤버,AI: === 토론 2: 분석 (20~35분) ===
    AI->>멤버: 질문 2 — 관점 교차 비교
    멤버->>AI: 심화 토론 (AI가 발언 균형 관리)

    Note over 멤버,AI: === 토론 3: 적용 (35~45분) ===
    AI->>멤버: 질문 3 — 현실 적용
    멤버->>AI: 사례 기반 토론

    Note over 멤버,AI: === 성찰 + 마무리 (45~60분) ===
    AI->>멤버: 전체 요약 + 관점 정리
    멤버->>AI: 각자 한 줄 성찰
    AI->>멤버: 다음 주 안내 + 성찰 질문
```

### 5.2 난이도별 콘텐츠 상세 비교

| 항목 | Level 1: 입문 ⭐ | Level 2: 심화 ⭐⭐ | Level 3: 융합 ⭐⭐⭐ |
|------|:---:|:---:|:---:|

| **세션 최대 시간** | 40분 (초등) ~ 60분 | 50분 ~ 70분 | 60분 ~ 90분 |
| **토론 초점** | 이해 + 감상 | 관점 비교 | 비판적 분석 + 통합 |
| **AI MC 질문** | "어떤 부분이 인상적?" | "A 관점 vs B 관점은?" | "저자들의 전제가 다른 이유는?" |
| **사고력 훈련** | 이해, 공감, 표현 | 비교, 분석, 논증 | 비판, 통합, 창조 |
| **기간** | 4주 (8회) | 6~8주 | 8~12주 |
| **콘텐츠 패키지** | 독서 가이드 + 질문 카드 | 관점 비교 워크시트 + 에세이 틀 | 분석 프레임워크 + 프로젝트 가이드 |

이 시간에 맞춰 질문 수와 깊이를 조절합니다.

- 20분 세션: 오프닝 질문 1개 + 마무리 = 가볍게
- 30분 세션: 질문 2개 (이해 + 감상) + 마무리
- 40분 세션: 질문 2개 + 후속 1개 + 성찰
- 50분 세션: 질문 3개 (이해/분석/적용) + 성찰
- 60분 세션: 질문 3개 + 후속 2개 + 심화 성찰
- 70분+ 세션: 본격 심화 토론 (기존 풀 구성)

[핵심 원칙]
1. 절대 정답을 말하지 않는다. 질문으로만 사고를 확장한다.
2. 모든 멤버에게 균등한 발언 기회를 준다.
3. 세션 시간을 절대 초과하지 않는다.
4. 짧은 세션일수록 따뜻하고 가볍게, 긴 세션일수록 깊이 있게.
5. {학년} 수준에 맞는 언어와 깊이로 대화한다.

[하지 않는 것]
- 자기 의견을 주장하지 않는다
- 특정 관점을 편들지 않는다
- 정답을 직접 말하지 않는다
- 멤버를 평가하거나 점수를 매기지 않는다
- 발언을 강제하지 않는다 (부드럽게 초대만)
- 욕설, 비방, 인신공격을 허용하지 않는다
```

{사용자 이름}이 {책 제목}을 읽고 있습니다.

[콘텐츠 제공 모드]
1. 독서 팁 모드: "이 책을 더 잘 읽는 법" 제공
   - 밑줄 치며 읽기 팁
   - 질문 만들며 읽기 팁
   - 다른 관점으로 읽기 팁

2. 배경지식 모드: "이 책을 이해하는 데 필요한 배경"
   - 저자 소개
   - 시대적 맥락
   - 관련 키워드 설명

3. 대화 모드: "읽은 내용에 대해 함께 이야기"
   - 탐구: "왜 그렇게 생각해요?"
   - 관점: "다른 입장에서 보면?"
   - 연결: "현실에서 비슷한 사례는?"
   - 정리: "지금까지 이야기를 정리하면?"

[제한]
- 스포일러 금지
- 학년 수준 이상의 어려운 개념은 쉽게 설명
- 1회 대화에서 질문 3개 이상 연속 금지
```

[실시간 감지 대상]

2. 인신공격 ("너는 바보야" 등)

5. 논점 이탈 공격 (사람을 공격, 주장이 아닌)

[대응 단계]
Level 1 (가벼운 위반):
  → AI MC가 자연스럽게 대화 전환
  → "좋은 열정이네요! 다른 관점에서 보면 어떨까요?"

[원칙]
- 검열이 아니라 보호
- 처벌이 아니라 안내
- "이런 말은 안 됩니다"가 아니라 "이렇게 말하면 더 좋습니다"
