## 2. 네비게이션 구조

### 2.1 하단 탭 바

```
┌──────────────────────────────────────────────┐
│                                              │
│     홈        탐색      (+)      내모임    MY │
│     🏠        🔍       ➕       📚       👤 │
│                                              │
└──────────────────────────────────────────────┘

- 홈: 개인화된 메인 피드
- 탐색: 전체 모임 브라우징 + 필터
- (+): 모임 만들기 (FAB 스타일, 강조)
- 내모임: 참여/운영 중인 모임 관리
- MY: 프로필, 성장, 학습, 설정
```

### 2.2 화면 전환 패턴

| 전환 유형 | 사용 위치 | 애니메이션 |
|----------|----------|-----------|
| **탭 전환** | 하단 탭 바 | 페이드 (탭 간 전환) |
| **Push** | 모임 카드 → 모임 상세 | 우측 슬라이드 |
| **Modal** | (+)만들기, 토론 라이브 | 하단에서 올라옴 |
| **풀스크린** | 토론 진행 화면 | 전체 화면 전환 |
| **바텀시트** | 필터, 빠른 설정 | 하단 반쯤 올라옴 |

## 3. 사용자 플로우

### 3.1 신규 사용자 (첫 토론까지)

```mermaid
flowchart TD
    A["앱 설치 / 접속"] --> B["온보딩 3장<br/>(리딩크루 소개)"]
    B --> C["소셜 로그인<br/>(카카오/네이버/애플)"]
    C --> D["프로필 설정<br/>닉네임 + 학년 + 관심분야"]
    D --> E["대화 서약 동의<br/>(건전한 토론 문화)"]
    E --> F["홈 화면 도착"]
    F --> G["추천 모임 탭<br/>or 학습 허브 배너"]
    G -->|"모임 선택"| H["모임 상세 확인"]
    G -->|"기본 배우기"| I["학습 허브<br/>(독서토론 길라잡이)"]
    H --> J["참여하기 버튼"]
    J --> K["토론 대기실<br/>(D-day까지 준비)"]
    K --> L["책 읽기 + 인사이트 카드"]
    L --> M["토론 라이브 접속!"]

    style A fill:#e1f5ff,color:#111
    style F fill:#4ECDC4,color:#fff
    style M fill:#FF6B6B,color:#fff
```

flowchart TD

    }
