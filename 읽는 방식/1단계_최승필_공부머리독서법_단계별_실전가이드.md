# 최승필 《공부머리 독서법》 기반
# 연령별 단계별 독서 방법론 실전 가이드

> **출처**: 최승필 저 《공부머리 독서법》(책구루, 2018) · 《다시, 공부머리 독서법》(2024)
> 경향신문 인생수업 강의, 중앙일보 인터뷰, 사교육걱정없는세상 인터뷰 종합
>
> **핵심 철학**: "공부머리는 지식이 아닌 **몰입**에서 나온다. 재미있는 독서만이 아이를 성장시킨다."
> — 최승필

## 📌 전체 로드맵 한눈에 보기

```
┌─────────────────────────────────────────────────────────────────────────────┐
│              최승필 공부머리 독서법 — 발달 단계별 전체 지도                  │
├──────────┬───────────┬──────────────────┬────────────────────────────────────┤
│  단계    │  대상     │  핵심 목표       │  대표 독서법                       │
├──────────┼───────────┼──────────────────┼────────────────────────────────────┤
│ 0단계    │ 영유아    │ 책 사랑 + 뇌 발달│ 하루 15분 읽어주기                 │
│          │ 0~7세     │ (조기교육 금지)  │ 그림책 상호작용 독서               │
├──────────┼───────────┼──────────────────┼────────────────────────────────────┤
│ 1단계    │ 초등 저   │ 읽기 독립        │ 반복독서 + 소리 내어 읽기          │
│          │ 1~2학년   │ (해독 완성)      │ 독서퀴즈대회 (방학)                │
├──────────┼───────────┼──────────────────┼────────────────────────────────────┤
│ 2단계    │ 초등 중   │ 이야기책 몰입    │ 자유독서 + 반복독서                │
│          │ 3~4학년   │ (장편동화 정복)  │ 슬로리딩 입문 (4학년~)             │
├──────────┼───────────┼──────────────────┼────────────────────────────────────┤
│ 3단계    │ 초등 고   │ 지식책 입문      │ 슬로리딩 + 독서퀴즈대회            │
│          │ 5~6학년   │ (정보 독해 시작) │ 이야기책 → 지식책 전환             │
├──────────┼───────────┼──────────────────┼────────────────────────────────────┤
│ 4단계    │ 중학생    │ 비판적 독자      │ 슬로리딩 + 필사 + 초록             │
│          │ 1~3학년   │ (사고력 독서)    │ 2주 1권 정독                       │
├──────────┼───────────┼──────────────────┼────────────────────────────────────┤
│ 5단계    │ 고등학생  │ 학문적 독서      │ 초록 + 필사 + 통합 독서            │
│          │ 1~3학년   │ (통합 사고력)    │ 교과 연계 심층 독서                │
└──────────┴───────────┴──────────────────┴────────────────────────────────────┘
```

> ⚠️ **최승필 선생님의 경고**
> "초등 1~2학년 때 책을 많이 읽던 아이도 **초등 3학년부터 독서율이 급락**하고,
> 중학생이 되면 **10%대**로 떨어진다. 이것은 갑작스러운 게 아니라
> 영유아기부터 쌓인 **잘못된 독서 교육**의 결과다."

## 🚫 최승필 선생님이 말하는 독서 교육의 3대 오류

```
┌─────────────────────────────────────────────────────────────────┐
│                    피해야 할 3가지 함정                          │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  ① 지식 중심 독서                                               │
│     "교과 연계 지식 전집이 도움이 될 거야"                       │
│     → 당장은 효과 있어 보이지만 장기적으로 손해                  │
│     → 지식책은 이야기책 기초가 완성된 후에 시작                  │
│                                                                 │
│  ② 부모가 책을 선택                                             │
│     "이 책이 좋은 책이니까 읽어"                                 │
│     → 외부에서 배달된 책은 집중력이 떨어짐                       │
│     → 아이가 스스로 고르게 해야 몰입이 생김                      │
│                                                                 │
│  ③ 속독 · 다독 강요                                             │
│     "책을 많이 읽어야 해"                                        │
│     → 눈으로 훑는 것은 읽기가 아님                               │
│     → 읽고 이해하는 것이 세트                                    │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

## 0단계 | 영유아 (0~7세)

### 핵심 원칙: 조기 교육 금지 + 책 사랑 형성

> **뇌과학 근거**: 영유아기 과도한 학습은 스트레스 호르몬 **코르티솔**을 분비시켜
> 기억을 담당하는 **해마의 성장을 방해**한다. (서유헌 교수, 한국뇌연구원 초대원장)

> 핀란드는 **8세 미만 아동에게 문자 교육을 법으로 금지**한다.
> 독일 초등학교 취학 통지서: *"입학 전 글자를 깨치면 교육과정에서 불이익을 받을 수 있습니다."*

### 🔊 핵심 방법: 하루 15분 책 읽어주기

```
┌─────────────────────────────────────────────────────────────────┐
│              하루 15분 책 읽어주기 — 실전 방법                   │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  📍 언제?  잠자리 전 고정 시간 (매일 같은 시간)                  │
│  📍 어디서? 부모 품에 안겨서 (스킨십 + 독서 동시에)              │
│  📍 어떻게?                                                     │
│                                                                 │
│    1. 표지 보며 "이 책 어떤 내용일까?" 함께 상상하기             │
│    2. 캐릭터마다 다른 목소리로 읽기 (과장된 연기 OK)             │
│    3. 중간에 멈추고 "다음에 어떻게 될 것 같아?" 묻기             │
│    4. 그림 속 세부 요소 함께 찾기 ("강아지 어디 있어?")          │
│    5. 읽은 후 "어떤 부분이 재미있었어?" 대화하기                 │
│                                                                 │
│  📍 얼마나? 같은 책 반복해도 OK — 반복이 언어 발달을 돕는다      │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

**왜 부모가 읽어줘야 하는가?**
- 오디오북은 **상호교감이 없어** 효과가 절반 이하
- 부모의 목소리 + 스킨십 + 감정 교류 = 대뇌변연계 발달의 핵심
- "책 = 행복한 경험"의 회로가 이 시기에 형성된다

### 🖼️ 그림책 상호작용 독서법

```
단계별 그림 읽기 훈련
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1단계 (0~2세): 명명하기
  → "이게 뭐야?" "강아지야!" 
  → 사물 인식 + 언어 연결

2단계 (2~3세): 묘사하기
  → "강아지가 뭐 하고 있어?" 
  → 행동과 상태를 언어로 표현

3단계 (3~5세): 감정 읽기
  → "이 아이 표정이 어때? 왜 그럴까?"
  → 정서 어휘 발달 + 공감 능력

4단계 (5~7세): 이야기 만들기
  → 그림만 보고 앞뒤 이야기 구성
  → 서사 구조 인식 + 상상력

5단계 (6~7세): 글과 그림 비교
  → "글에는 없는데 그림에는 뭐가 있어?"
  → 정보 통합 능력 + 비교 사고
```

### 핵심 원칙: 읽기 독립 + 소리 내어 읽기 유창성

> **최승필 선생님**: "읽기 독립을 빨리 유도하면 더 잘 읽을 수 있을까?

### 🔊 소리 내어 읽기 — 이 시기 최우선 훈련

```
소리 내어 읽기 4단계 훈련법
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

① 따라 읽기 (Echo Reading)
   부모/교사가 한 문장 읽기 → 아이가 똑같이 따라 읽기
   목적: 억양, 끊어 읽기, 속도 모델링
   예시: "토끼가 / 깡충깡충 / 뛰어갔어요."
         ↓ 아이가 따라 읽기

② 함께 읽기 (Choral Reading)  
   같은 텍스트를 부모와 아이가 동시에 함께 읽기
   목적: 자신감 형성, 유창성 향상

③ 반복 읽기 (Repeated Reading) ← 최승필 선생님 강조
   같은 짧은 글을 3~5번 반복해서 읽기
   목적: 유창성 자동화 — 가장 효과적인 방법
   
④ 녹음 후 듣기
   아이가 읽는 것을 녹음 → 함께 들으며 확인
   목적: 자기 모니터링, 표현력 향상
```

**실전 예시 — 반복 읽기 훈련**

```
[사용 텍스트] 짧은 동화 한 단락 (5~7문장)

1회차: 천천히, 틀려도 OK — "그냥 읽어봐"
2회차: 조금 더 빠르게 — "이번엔 좀 더 빠르게"
3회차: 자연스럽게 — "이야기하듯이 읽어봐"
4회차: 표현력 추가 — "캐릭터가 된 것처럼"
5회차: 완성 — 녹음해서 들어보기

→ 같은 글을 5번 읽으면 유창성이 눈에 띄게 향상된다
```

### 📖 자유독서 + 반복독서

```
  교과서 단원 → 관련 역사서 발췌 읽기

  수능 지문 유형별 → 관련 분야 입문서 읽기
  → 배경지식 축적 → 독해 속도 향상
```
