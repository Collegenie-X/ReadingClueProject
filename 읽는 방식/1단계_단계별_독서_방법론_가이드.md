## 유아기

### 만 3~6세 | 소리와 그림으로 세계를 만나다

> **이 시기의 목표**: 책은 즐거운 것이라는 경험 + 언어의 소리 구조 인식 + 그림으로 이야기 읽기

---

### 🔊 1. 소리 내어 읽기 (Read-Aloud) — 가장 중요한 기본기

**왜 중요한가?**
- 문자를 모르는 아이가 언어의 리듬, 억양, 어휘를 흡수하는 유일한 통로
- 어른의 목소리로 읽어주는 경험이 "책 = 즐거움"의 회로를 만든다
- 이 시기 어휘 노출량이 초등 이후 독해력을 결정한다 (Hart & Risley 연구)

**실천 방법**

| 방법 | 구체적 실천 |
|------|------------|
| **하루 20분 읽어주기** | 잠자리 전 고정 시간 확보. 같은 책을 반복해도 좋다 |
| **손가락으로 짚으며 읽기** | 글자와 소리의 연결을 자연스럽게 학습 |
| **표정·목소리 변화** | 캐릭터마다 다른 목소리로 읽어 극적 몰입 유도 |
| **중간에 멈추고 묻기** | "다음에 어떻게 될 것 같아?" — 예측 사고 훈련 |
| **아이가 읽어주는 척** | 그림을 보며 이야기를 만들게 한다 |

---

### 🖼️ 2. 그림 읽기 (Visual Literacy) — 문해력의 첫 번째 형태

**핵심 개념**: 그림책의 그림은 장식이 아니라 텍스트다.

**단계별 그림 읽기 훈련**

```
1단계: 명명하기
   → "이게 뭐야?" "강아지야!" — 사물 인식과 언어 연결

2단계: 묘사하기
   → "강아지가 뭐 하고 있어?" — 행동과 상태 언어화

3단계: 감정 읽기
   → "이 아이 표정이 어때? 왜 그럴까?" — 정서 어휘 발달

4단계: 이야기 만들기
   → 그림만 보고 앞뒤 이야기 구성 — 서사 구조 인식

5단계: 글과 그림 비교하기
   → "글에는 없는데 그림에는 뭐가 있어?" — 정보 통합 능력
```

**추천 활동**: 워드리스 픽처북(글 없는 그림책) 활용
- 예: 이수지 작가의 《파도야 놀자》, 《그림자놀이》
- 아이가 직접 이야기를 말하게 한다 → 구술 표현력 + 서사 구조 동시 훈련

---

### 👂 3. 음운 인식 (Phonological Awareness) — 읽기의 숨겨진 기초

**음운 인식이란?** 말소리의 구조를 인식하는 능력. 글자를 배우기 전에 반드시 발달해야 한다.

**훈련 순서 (쉬운 것 → 어려운 것)**

```
① 단어 인식: "사과"는 몇 글자야? → 2글자
② 음절 분리: "나비"를 쪼개면? → 나 / 비
③ 두운 인식: "바나나, 바람, 바다" — 같은 소리로 시작하는 말 찾기
④ 각운 인식: "강아지, 고양이, 다람쥐" — 끝소리 비교
⑤ 음소 조작: "바"에서 "ㅂ"을 빼면? → "아"
```

**놀이로 훈련하기**
- 끝말잇기, 동요 부르기, 말놀이 그림책
- 박수치며 음절 세기: "토-끼" (박수 2번)
- 수수께끼: "ㅅ으로 시작하는 동물은?" → 사자, 사슴, 소...

---

### 📚 4. 환경 인쇄물 읽기 (Environmental Print)

- 간판, 메뉴판, 과자 봉지의 글자에 관심 갖게 하기
- "저거 뭐라고 써 있을까?" → 글자가 의미를 담고 있다는 인식 형성
- 자기 이름 쓰기/읽기 → 문자 학습의 동기 부여

---

### ✅ 유아기 체크리스트

- [ ] 하루 1권 이상 책을 함께 읽는다
- [ ] 그림을 보며 이야기를 말할 수 있다
- [ ] 동요·동시를 즐겨 부른다 (음운 인식)
- [ ] 자기 이름의 글자를 안다
- [ ] "책 읽어줘"라고 스스로 요청한다

## 초등 저학년

### 1~2학년 | 해독(Decoding)의 완성

> **이 시기의 목표**: 글자와 소리의 완전한 연결 + 소리 내어 읽기 유창성 확보

---

### 🔊 1. 소리 내어 읽기 — 이 시기의 핵심 훈련

**왜 소리 내어 읽어야 하는가?**

묵독은 소리 내어 읽기가 자동화된 이후에 가능하다. 이 시기에 소리 내어 읽기를 충분히 훈련하지 않으면:
- 묵독 시 입술을 움직이거나 속으로 소리를 내는 습관이 고착된다
- 읽기 속도가 느려지고 이해력도 떨어진다
- 긴 글을 읽을 때 쉽게 지친다

**소리 내어 읽기 훈련법**

```
① 따라 읽기 (Echo Reading)
   교사/부모가 한 문장 읽기 → 아이가 똑같이 따라 읽기
   목적: 억양, 끊어 읽기, 속도 모델링

② 함께 읽기 (Choral Reading)
   같은 텍스트를 동시에 함께 읽기
   목적: 자신감 형성, 유창성 향상

③ 짝 읽기 (Partner Reading)
   한 문단씩 번갈아 읽기
   목적: 집중력 유지, 상호 피드백

④ 반복 읽기 (Repeated Reading)
   같은 짧은 글을 3~5번 반복
   목적: 유창성 자동화 — 가장 효과적인 방법
```

**유창성의 3요소**

| 요소 | 의미 | 훈련 방법 |
|------|------|-----------|
| **정확성** | 글자를 틀리지 않고 읽기 | 모르는 글자 짚어주기, 소리 내어 확인 |
| **속도** | 적절한 빠르기로 읽기 | 1분 읽기 테스트, 타이머 활용 |
| **표현력** | 의미에 맞게 억양 조절 | 연극처럼 읽기, 녹음 후 듣기 |

---

### 🔤 2. 파닉스와 어휘 — 해독의 엔진

**한글 파닉스 학습 순서**

```
1단계: 자음·모음 기본 결합
   가나다라마바사아자차카타파하
   아야어여오요우유으이

2단계: 받침 없는 글자 읽기
   가구기고그게 / 나누니노느네...

3단계: 받침 있는 글자
   받침 ㄱ,ㄴ,ㄷ,ㄹ,ㅁ,ㅂ,ㅇ → 단어 읽기

4단계: 복잡한 모음·이중 받침
   의,외,왜,위 / 닭,흙,읽다...

5단계: 불규칙 발음 규칙
   연음: 국어 → [구거]
   경음화: 학교 → [학꾜]
   구개음화: 굳이 → [구지]
```

**어휘 학습 전략 — "단어 지도" 만들기**

새 단어를 만나면:
1. 문장 속에서 뜻 추측하기
2. 사전에서 확인하기
3. 그림이나 예문으로 기억하기
4. 직접 문장 만들어 쓰기

---

### 🖼️ 3. 이미지와 텍스트 연결 읽기

이 시기 아이들은 여전히 그림에서 많은 정보를 얻는다.

**그림책 → 글 중심 책으로의 전환 전략**

```
그림책 (그림 70% + 글 30%)
    ↓
초기 챕터북 (그림 30% + 글 70%)
    ↓
챕터북 (그림 10% + 글 90%)
    ↓
소설·정보책 (그림 없음)
```

**이미지 활용 독서 활동**
- 읽기 전: 표지 그림 보고 내용 예측하기
- 읽는 중: 그림과 글의 일치/불일치 찾기
- 읽은 후: 장면 그림 그리기 → 시각적 재구성

---

### 📖 4. 이해력 기초 — 5가지 W 질문

모든 이야기를 읽은 후 반드시 확인:

```
Who   → 누가 나왔어?
What  → 무슨 일이 있었어?
When  → 언제 일어난 일이야?
Where → 어디서 있었던 일이야?
Why   → 왜 그런 일이 생겼어?
How   → 어떻게 해결됐어?
```

---

### ✅ 초등 저학년 체크리스트

- [ ] 모든 글자를 정확하게 소리 내어 읽을 수 있다
- [ ] 1분에 60~80자 이상 유창하게 읽는다
- [ ] 읽은 이야기의 주요 내용을 말할 수 있다
- [ ] 모르는 단어를 문맥에서 추측하려 시도한다
- [ ] 책 읽기를 스스로 즐긴다

## 초등 중학년

### 3~4학년 | 유창성과 이해의 교차점

> **이 시기의 목표**: 유창한 묵독으로 전환 + 능동적 이해 전략 체득 + 어휘 폭발적 확장

---

### 🤫 1. 묵독으로의 전환 — 읽기의 내면화

**전환 시기 판단 기준**
- 소리 내어 읽기가 완전히 유창해졌을 때
- 1분에 100자 이상 정확하게 읽을 수 있을 때
- 읽으면서 내용을 동시에 이해할 수 있을 때

**전환 방법**
```
1단계: 속삭이며 읽기 (Whisper Reading)
   → 소리를 줄여가며 읽기

2단계: 입술만 움직이며 읽기
   → 소리는 내지 않되 입 모양 유지

3단계: 완전한 묵독
   → 눈으로만 읽기
```

> ⚠️ 주의: 묵독으로 전환했다고 소리 내어 읽기를 완전히 중단하면 안 된다.
> 어려운 텍스트, 시, 연설문은 계속 소리 내어 읽어야 한다.

---

### 🧠 2. 능동적 이해 전략 6가지

이 시기부터 "전략적 독자"가 되는 훈련을 시작한다.

#### 전략 1: 예측하기 (Predicting)
```
읽기 전: 제목, 표지, 목차를 보고 내용 예측
읽는 중: "다음에 어떻게 될까?" 지속적으로 예측
읽은 후: 예측이 맞았는지 확인하고 이유 생각하기
```

#### 전략 2: 연결하기 (Connecting)
```
텍스트 ↔ 자신 (T-S): 내 경험과 연결
텍스트 ↔ 텍스트 (T-T): 다른 책과 연결
텍스트 ↔ 세계 (T-W): 실제 세상과 연결
```

#### 전략 3: 질문하기 (Questioning)
```
사실 질문: 글에 답이 있는 질문
추론 질문: 글 사이에서 답을 찾아야 하는 질문
비판 질문: 글 밖에서 생각해야 하는 질문
```

#### 전략 4: 시각화하기 (Visualizing)
```
읽으면서 장면을 머릿속에 그리기
→ 등장인물의 모습 상상하기
→ 배경 장소 그려보기
→ 사건의 순서를 그림으로 표현하기
```

#### 전략 5: 추론하기 (Inferring)
```
글에 직접 나오지 않는 정보를 단서로 파악하기
예: "민준이는 우산을 챙겼다" → 비가 올 것 같다고 생각했다
```

#### 전략 6: 요약하기 (Summarizing)
```
중요한 것과 중요하지 않은 것 구별하기
→ 핵심 사건 3가지만 고르기
→ 한 문장으로 줄이기
→ 제목 붙이기
```

### 📚 4. 어휘 확장 — 어휘 폭발의 시기

3~4학년은 어휘 학습의 황금기다. 이 시기 어휘력이 이후 모든 교과 학습의 기반이 된다.

**어휘 학습 4단계**

```
1단계: 만나기 — 다양한 텍스트에서 새 단어 만나기
2단계: 추측하기 — 문맥에서 뜻 추측하기
3단계: 확인하기 — 사전·어른에게 확인하기
4단계: 사용하기 — 말하기·쓰기에서 직접 사용하기
```

**어휘 확장 활동**
- 어휘 노트 만들기: 단어 + 뜻 + 예문 + 그림
- 어원 탐구: 한자어 분해 (예: 독서 = 읽을 독 + 글 서)
- 단어 연상 게임: "행복"하면 떠오르는 단어 10개

- [ ] 읽기 전 예측하기를 습관적으로 한다
- [ ] 읽으면서 장면을 머릿속에 그린다
- [ ] 읽은 내용을 간단하게 요약할 수 있다
- [ ] 독서 노트를 꾸준히 쓴다

## 초등 고학년

### 5~6학년 | 읽기로 배우기의 시작

> **이 시기의 목표**: 정보 텍스트 읽기 + 추론과 비판의 시작 + 장르별 읽기 전략 분화

---

### 📊 1. 정보 텍스트 읽기 (Informational Text Reading)

이 시기부터 이야기책(서사)과 정보책(설명·논설)을 구별하여 읽어야 한다.

**서사 텍스트 vs 정보 텍스트 읽기 전략 비교**

| 구분 | 서사 텍스트 | 정보 텍스트 |
|------|------------|------------|
| **목적** | 이야기 즐기기, 공감 | 정보 획득, 학습 |
| **읽기 순서** | 처음부터 끝까지 | 목차 → 필요한 부분 |
| **핵심 파악** | 주제, 인물, 갈등 | 핵심 개념, 인과관계 |
| **메모 방법** | 인상적인 장면, 감상 | 개념도, 핵심어 정리 |
| **읽은 후** | 감상문, 토론 | 요약, 정리, 적용 |

**정보 텍스트 구조 5가지**

```
① 기술/묘사: 대상의 특징을 설명
   → 핵심어와 세부 정보 구분하며 읽기

② 순서/절차: 시간 순서나 단계 설명
   → 순서도(플로우차트) 그리며 읽기

③ 비교/대조: 두 가지 이상을 비교
   → 벤다이어그램 그리며 읽기

④ 원인/결과: 왜 일어났는지 설명
   → 원인→결과 화살표로 정리

⑤ 문제/해결: 문제와 해결책 제시
   → 문제-해결 표로 정리
```

---

### 🔍 2. 추론 읽기 — 행간을 읽다

**추론의 3단계**

```
1단계: 사실 확인 (글에 있는 정보)
   "글에서 직접 찾을 수 있는 내용은?"

2단계: 추론 (글의 단서 + 배경지식)
   "글에서 직접 말하지 않지만 알 수 있는 것은?"

3단계: 비판/평가 (글 밖의 판단)
   "이 내용에 동의하는가? 왜?"
```

**추론 연습 — "왜냐하면" 훈련**
```
글의 단서: "철수는 창문을 닫았다."
추론: 철수는 추웠을 것이다.
근거: 왜냐하면 추울 때 창문을 닫기 때문이다.
```

---

### 📖 3. 장르별 읽기 전략

**소설 읽기**
```
인물 분석: 성격 + 변화 + 동기
배경 분석: 시간·공간이 이야기에 미치는 영향
갈등 구조: 인물 vs 인물 / 인물 vs 환경 / 인물 vs 자신
주제 파악: 작가가 말하고자 하는 것
```

**시 읽기**
```
소리 내어 읽기 (리듬과 운율 느끼기)
이미지 찾기 (감각적 표현)
비유 분석 (직유, 은유, 의인화)
화자의 감정 파악
```

**논설문 읽기**
```
주장 찾기 → 근거 찾기 → 근거의 타당성 평가
반론 찾기 → 반론에 대한 재반박 확인
나의 의견과 비교하기
```

---

### 📝 4. SQ3R 읽기 전략 — 교과서 읽기의 기본

```
S — Survey (훑어보기)
    제목, 소제목, 그림, 굵은 글씨 먼저 훑기

Q — Question (질문 만들기)
    소제목을 질문으로 바꾸기
    예: "광합성의 과정" → "광합성은 어떻게 일어나는가?"

R — Read (읽기)
    질문에 답을 찾으며 읽기

R — Recite (말하기)
    책을 덮고 질문에 답하기

R — Review (복습하기)
    전체 내용 정리하고 확인하기
```

## 중학생

### 1~3학년 | 비판적 독자로의 전환

> **이 시기의 목표**: 비판적 읽기 + 관점 분석 + 논증 구조 파악 + 다양한 텍스트 통합

---

### 🧐 1. 비판적 읽기 — 텍스트를 의심하라

**비판적 읽기의 4가지 질문**

```
① 신뢰성 질문: "이 정보는 믿을 수 있는가?"
   → 저자는 누구인가? 출처는 어디인가? 근거가 충분한가?

② 편향성 질문: "이 글은 어떤 관점에서 쓰였는가?"
   → 어떤 정보가 빠져 있는가? 특정 입장을 지지하는가?

③ 목적 질문: "왜 이 글을 썼는가?"
   → 정보 제공? 설득? 오락? 광고?

④ 영향 질문: "이 글이 독자에게 미치는 영향은?"
   → 어떤 감정을 유발하는가? 어떤 행동을 유도하는가?
```

---

### ⚖️ 2. 논증 구조 분석

**논증의 기본 구조**

```
주장 (Claim)
    ↓
근거 (Evidence)
    ↓
이유 (Reasoning) — 근거가 주장을 지지하는 이유
    ↓
반론 고려 (Counterargument)
    ↓
반론 반박 (Rebuttal)
```

**논증 분석 실습**
1. 신문 사설 하나 선택
2. 주장 한 문장으로 정리
3. 근거 3가지 찾기
4. 각 근거의 타당성 평가 (사실인가? 충분한가? 관련 있는가?)
5. 반론 제시하기

---

### 🔄 3. 다관점 읽기 — 같은 사건, 다른 시각

**방법**
1. 하나의 주제에 대해 서로 다른 입장의 글 2~3편 읽기
2. 각 글의 주장과 근거 정리
3. 공통점과 차이점 분석
4. 자신의 입장 정립

**추천 주제**
- 학교 스마트폰 사용 금지 찬반
- 동물원의 존재 의미
- 역사적 인물 평가 (예: 이순신, 세종대왕)

---

### 📚 4. 장편 소설 읽기 — 지속적 독서의 훈련

**장편 소설을 읽어야 하는 이유**
- 집중력과 지속적 주의력 훈련
- 복잡한 인물 관계와 플롯 추적 능력
- 긴 호흡의 사고 훈련

**장편 소설 읽기 전략**

```
읽기 전:
  - 작가와 시대적 배경 조사
  - 첫 챕터 읽고 등장인물 목록 만들기

읽는 중 (챕터별):
  - 핵심 사건 1~2줄 메모
  - 인물의 변화 추적
  - 복선과 상징 표시

읽은 후:
  - 전체 플롯 구조 그리기
  - 주제 분석
  - 작가의 의도 추론
```

---

### 📰 5. 미디어 리터러시 — 디지털 시대의 독서

**미디어 텍스트 읽기 원칙**

```
① 출처 확인: 누가 만들었는가?
② 목적 파악: 왜 만들었는가?
③ 기법 분석: 어떤 방법으로 메시지를 전달하는가?
④ 가치관 파악: 어떤 가치를 담고 있는가?
⑤ 빠진 것 찾기: 무엇이 생략되었는가?
```

---

### ✅ 중학생 체크리스트

- [ ] 글쓴이의 관점과 의도를 파악하며 읽는다
- [ ] 주장과 근거를 구분하고 타당성을 평가한다
- [ ] 같은 주제의 다른 관점 글을 비교 읽는다
- [ ] 장편 소설을 끝까지 읽고 분석할 수 있다
- [ ] 인터넷 정보의 신뢰성을 판단한다

## 고등학생

### 1~3학년 | 학문적·전략적 독서의 완성

> **이 시기의 목표**: 학문적 독서 + 메타인지 독해 + 통합적 사고 + 자기주도 독서 설계

---

### 🎓 1. 학문적 독서 — 교과별 읽기 전략

각 교과의 텍스트는 구조와 언어가 다르다. 교과별로 다른 전략이 필요하다.

**국어/문학**
```
시: 화자 → 상황 → 정서 → 표현 방식 → 주제
소설: 인물 → 배경 → 사건 → 갈등 → 주제
비문학: 주제문 → 전개 방식 → 논리 구조 → 필자의 관점
```

**사회/역사**
```
역사적 맥락 파악 → 인과관계 분석 → 다양한 해석 비교
1차 사료 vs 2차 사료 구분
시대적 관점에서 읽기 (당시 기준으로 판단)
```

**과학**
```
가설 → 실험 → 결과 → 결론 구조 파악
그래프·표·다이어그램과 본문 연결
전문 용어 정확한 이해
반증 가능성 생각하기
```

**수학**
```
정의 → 정리 → 증명 → 예제 순서로 읽기
모든 조건의 의미 파악
예제를 직접 풀어보며 읽기
```

---

### 🧠 2. 메타인지 독서 — 나의 읽기를 읽다

**메타인지란?** 자신의 사고 과정을 인식하고 조절하는 능력.

**메타인지 독서의 3단계**

```
① 계획 (Planning)
   "이 글을 왜 읽는가? 무엇을 알고 싶은가?"
   "얼마나 깊이 읽어야 하는가?"
   "어떤 전략을 쓸 것인가?"

② 모니터링 (Monitoring)
   "지금 이해하고 있는가?"
   "이해가 안 되는 부분은 어디인가?"
   "전략을 바꿔야 하는가?"

③ 평가 (Evaluating)
   "목표를 달성했는가?"
   "무엇을 배웠는가?"
   "다음에는 어떻게 다르게 읽을 것인가?"
```

**이해 점검 신호**
```
이해하고 있을 때:
  ✓ 읽으면서 머릿속에 그림이 그려진다
  ✓ 앞 내용과 연결된다
  ✓ 예측이 맞아 들어간다

이해가 안 될 때:
  ✗ 같은 문장을 여러 번 읽게 된다
  ✗ 머릿속이 멍하다
  ✗ 앞 내용이 기억나지 않는다
  → 이때: 다시 읽기, 소리 내어 읽기, 요약하기
```

---

### 📖 3. 심층 독서 전략 — SQ4R + 코넬 노트

**SQ4R (SQ3R 확장)**

```
S — Survey: 전체 훑기 (5분)
Q — Question: 질문 만들기
R — Read: 질문 답 찾으며 읽기
R — Reflect: 배운 것을 기존 지식과 연결
R — Recite: 책 덮고 말하기
R — Review: 24시간 후 복습
```

**코넬 노트 활용**

```
┌─────────────────┬──────────────────────────────┐
│                 │                              │
│  핵심어/질문    │      상세 내용 메모          │
│  (좌측 1/3)    │      (우측 2/3)              │
│                 │                              │
│                 │                              │
│                 │                              │
├─────────────────┴──────────────────────────────┤
│              요약 (하단 1/5)                    │
│  핵심 내용을 2~3문장으로 정리                   │
└────────────────────────────────────────────────┘
```

---

### 🔗 4. 통합적 읽기 — 여러 텍스트를 하나로

**통합 읽기의 3단계**

```
1단계: 개별 텍스트 이해
   각 글의 주장, 근거, 관점 정리

2단계: 텍스트 간 비교
   공통점 / 차이점 / 상호 보완 / 모순 찾기

3단계: 통합적 해석
   여러 텍스트를 종합하여 자신의 관점 형성
   새로운 질문 생성
```

---

### ✍️ 5. 독서와 글쓰기의 통합

고등학교 수준에서 독서는 글쓰기와 분리될 수 없다.

**독서 → 글쓰기 연결 방법**

```
요약문 쓰기: 핵심 내용을 자신의 언어로 재구성
서평 쓰기: 내용 + 평가 + 추천 이유
비교 분석문: 두 텍스트의 공통점·차이점 분석
논술: 텍스트를 근거로 자신의 주장 전개
연구 보고서: 여러 텍스트를 통합하여 새로운 주장
```

---

### 📅 6. 자기주도 독서 계획 수립

**연간 독서 계획 프레임**

```
목표 설정:
  - 올해 읽을 책 권수: ___권
  - 읽고 싶은 분야: ___
  - 도전하고 싶은 장르: ___

월별 계획:
  - 이번 달 읽을 책: ___
  - 읽는 목적: ___
  - 읽기 방법: ___

독서 후 활동:
  - 독서 노트 작성
  - 토론 참여
  - 글쓰기 연결
```

  ✓ 비판적 읽기 습관화
  ✓ 논증 구조 분석 가능
  ✓ 다관점 읽기 가능

### 전 단계 공통 원칙

```
① 소리 내어 읽기는 모든 단계에서 계속된다
   — 어려운 텍스트, 시, 연설문은 항상 소리 내어

② 즐거움이 먼저다
   — 강제로 읽히면 독서 혐오가 생긴다
   — 아이가 원하는 책을 선택하게 한다

③ 양보다 깊이
   — 한 권을 제대로 읽는 것이 열 권 훑는 것보다 낫다

④ 대화가 독서를 완성한다
   — 읽은 후 이야기 나누기가 이해를 2배로 만든다

⑤ 모델링이 최고의 교육이다
   — 어른이 책 읽는 모습을 보여주는 것이 최선
```

## 부모·교사를 위한 실천 체크리스트

### 환경 만들기

- [ ] 집/교실에 책이 손에 닿는 곳에 있다
- [ ] 독서를 위한 조용한 시간이 확보되어 있다
- [ ] 아이가 직접 책을 고를 수 있다
- [ ] 어른이 책 읽는 모습을 보여준다

### 상호작용

- [ ] 읽어준 후 내용에 대해 대화한다
- [ ] "왜?"라는 질문을 자주 한다
- [ ] 아이의 생각을 판단하지 않고 들어준다
- [ ] 틀린 추론도 과정을 칭찬한다

### 단계 점검

- [ ] 현재 단계의 기본기가 완성되었는지 정기적으로 확인한다
- [ ] 어려움이 있으면 이전 단계로 돌아간다
- [ ] 진도보다 깊이를 우선한다

## 참고: 독서 방법론 핵심 용어 정리

| 용어 | 설명 |
|------|------|
| **음운 인식** | 말소리의 구조를 인식하는 능력. 읽기 학습의 전제 조건 |
| **파닉스** | 글자와 소리의 대응 규칙 학습 |
| **유창성** | 정확하고 빠르고 표현력 있게 읽는 능력 |
| **해독** | 글자를 소리로 변환하는 과정 |
| **독해** | 텍스트의 의미를 이해하는 과정 |
| **메타인지** | 자신의 사고 과정을 인식하고 조절하는 능력 |
| **추론** | 글에 직접 나오지 않는 정보를 단서로 파악하는 것 |
| **비판적 읽기** | 텍스트의 신뢰성, 편향, 목적을 분석하며 읽기 |
| **통합적 읽기** | 여러 텍스트를 연결하여 종합적으로 이해하기 |
| **문해력** | 텍스트를 읽고 이해하고 활용하는 총체적 능력 |

---

> **마지막으로**: 독서 방법론은 도구다. 도구는 사용할 때 의미가 있다.
> 가장 중요한 것은 아이가 **책을 사랑하게 되는 것**이다.
> 방법론은 그 사랑을 더 깊고 넓게 만들기 위한 수단임을 잊지 말자.
