# 📚 리딩크루 — 독서의 목표

> **한 줄 정의**
> 리딩크루의 독서는 **질문에서 시작해서 해결에서 끝난다.**
> 질문만 던지고 끝나면 관념이 되고, 해결만 좇으면 남의 문제를 푼다.
> **내 질문에서 시작해서 내 손으로 검증하는 것** — 그것이 이 문서가 말하는 독서다.

## 0. 3단계 개요

```
┌───────────────┐    ┌───────────────┐    ┌───────────────┐
│  1. 발견      │ →  │  2. 질문      │ →  │  3. 해결      │
│  (Discover)   │    │  (Question)   │    │  (Solve)      │
├───────────────┤    ├───────────────┤    ├───────────────┤
│ 무엇에 자꾸   │    │ 이건 정말     │    │ 그래서 나는   │
│ 걸려 넘어지나 │    │ 문제인가      │    │ 무엇을 만드나 │
└───────────────┘    └───────────────┘    └───────────────┘
     관심사 태깅          렌즈 · 반증           프로토타입
     (재미 · 성찰)      (비판 · 통합)         (창조 · 실천)
```

이 세 단계는 **한 번 밟고 끝이 아니다.** 3단계에서 나온 결과가 새로운 1단계 재료가 된다.
"완성된 프로젝트보다 죽은 가설의 기록이 더 많은 것을 증명한다."

---

## 1단계 · 발견 — 무엇에 자꾸 걸려 넘어지나

### 왜 이 단계가 필요한가

문제 정의를 잘하려면 **내 문제**여야 한다. 남의 문제로는 오래 못 판다.
발견 단계는 "잘 읽는 법"이 아니라 **"내가 무엇에 걸려 넘어지는지 알아채는 법"**을 훈련한다.

### 이 단계에서 하는 일

| 활동 | 산출물 |
|------|--------|
| 자발적으로 30분 이상 파본 것 3개 떠올리기 | 관심사 후보 3개 |
| "다들 원래 그런 거래"에 승복 안 됐던 순간 쓰기 | 억울했던 규칙 1건 |
| 관심사 50 격자에 자기 태깅 (최대 5개) | 관심사 Top 3 |
| Top 관심사의 책 1권 목차 훑기 | 서가 등록 1권 |

### 이 단계에서 챙길 독서 목표

- **재미** — 자발적 몰입 없이 발견되는 관심사는 없다. 재미는 발견의 원료다.
- **성찰** — 감정이 아니라 **격자 위의 좌표**로 자신을 정리한다.

### 🚫 자주 하는 오해

| 오해 | 실제 |
|------|------|
| "재미있는 책을 많이 읽자" | 재미는 결과이지 목표가 아니다. **자발적 몰입의 이력**을 남기는 것이 목표 |
| "나를 알자" | 무엇을 아는지가 문제. **"내가 자꾸 걸려 넘어지는 것"** 이 유일한 재료 |
| "관심사가 여러 개라 못 정하겠다" | 최대 5개까지 태깅 가능. **딱 맞는 게 없으면 가장 가까운 것** |

## 2단계 · 질문 — 이건 정말 문제인가

### 왜 이 단계가 필요한가

발견한 관심사를 그대로 프로젝트로 옮기면 대부분 **누구나 3초 만에 떠올리는 답**이 나온다.
질문 단계는 그 첫 생각을 **봉인**하고, 두 번째·세 번째 생각으로 내려간다.
**이 단계가 리딩크루가 다른 독서 프로그램과 갈리는 지점이다.**

### 이 단계에서 하는 일

#### ① 병렬 독서 — 한 관심사, 세 종류의 책

```
[정의서 3권] 이 주제를 처음 정의한 저자들
[도구서 3권] 이 주제를 다룰 방법을 제안하는 저자들
[반증서 2권] 이 주제를 다르게 보거나 반대하는 저자들
─────────────
= 관심사 하나에 8권을 겹쳐 읽는다
```

> **왜 겹쳐 읽는가**: 한 저자만 읽으면 확신이 자라고, 다르게 읽은 사람과 만나면 질문이 자란다.
> AI 요약을 붙이면 이 겹침이 죽는다. 그래서 리딩크루는 **요약을 주지 않는다.**

#### ② 3개의 핵심 렌즈

발견한 관심사에 다음 세 렌즈만 대본다. (전체 12렌즈 중 이 세 개가 가장 자주 쓰인다)

| 렌즈 | 던지는 질문 | 산출물 |
|------|-------------|--------|
| **분석수준 렌즈** | 사람 문제인가, 규칙 문제인가, 문화 문제인가? | 3층 분해표 |
| **반증 렌즈** | 내가 틀렸다면 무엇이 관찰되는가? | 반증 조건 1개 |
| **반대편 렌즈** | 이 문제 해결을 가장 강하게 반대할 사람은? | 반대편 대변인 대본 |

#### ③ 금지된 답 봉인

첫 생각 3개를 적고 **🚫 표시로 봉인한다.** 이 세 개는 답으로 채택하지 않는다.

```
관심사 예시: #26 번아웃과 무기력
🚫 "휴식 시간을 정해두자"   → 이미 다들 안다. 안 지켜질 뿐
🚫 "스마트폰을 줄이자"      → 원인과 증상을 바꿔친 답
🚫 "마음챙김 앱"            → 앱 3만 개가 이미 있다
```

### 이 단계에서 챙길 독서 목표

- **비판적 독서** — 저자 주장의 편향·전제·반증 가능성을 판별한다.
- **통합적 독서** — 정의서·도구서·반증서를 매트릭스로 겹친다. **리딩크루의 핵심 방법.**
- **공감** — 감정이입이 아니라 **반대편 대변인 대본을 쓸 수 있는 상상력.**

### 이 단계의 산출물 — 문제 정의서 1장

```
관심사       : #26 번아웃과 무기력
핵심 긴장    : 쉬면 회복된다는데, 쉬고 와도 그대로다.
질문 선언문  : "우리 반의 피로는 공부량이 아니라
              쉬는 시간이 5분 단위로 쪼개진 시간표에서 온다"
금지된 답 3  : (위 예시 참조)
반증 조건    : "시간표를 통으로 재구성해도 피로도가 같으면 가설 폐기"
반대편 1인   : 시간표 세분화로 이득을 보는 담당 교사
```

**여기까지가 2단계다. 여기서 끝나면 관념이다.**

## 3단계 · 해결 — 그래서 나는 무엇을 만드나

### 왜 이 단계가 필요한가

질문만 있고 해결이 없으면 학생은 **"세상은 복잡하다"**만 배운다.
해결 단계는 **작더라도 손에 잡히는 산출물**을 요구한다.
프로토타입은 실패해도 좋다. 실패는 자산으로 등록된다.

### 🧱 대전제 — 해결은 "가진 자원"에서 시작한다

> **"예산이 100억 있다면"으로 시작하는 해결책은 해결책이 아니라 소원이다.**
> 리딩크루의 해결은 **지금 내 손에 있는 자원**에서 출발한다.

해결을 설계하기 전, 반드시 **자원 지도**를 먼저 그린다.

```
┌─────────────────────────────────────────────────┐
│  🧱 자원 지도 — 내가 지금 쓸 수 있는 것          │
├─────────────────────────────────────────────────┤
│  시간     : 하루 __시간 × 주 __일 × 총 __주    │
│  사람     : 우리 반 __명 · 협력 가능한 어른 __명│
│  공간     : 교실 · 도서관 · 동네 __            │
│  돈       : 0원 / 학교 지원금 __원 / 기타      │
│  도구     : 스마트폰 · 노트 · 학교 컴퓨터 · __ │
│  데이터   : 우리 반 __명에게 물을 수 있음      │
│  권한     : 게시판 · 방송실 · 학급회의 __      │
└─────────────────────────────────────────────────┘

⚠️ 이 표에 없는 자원을 전제한 해결책은 반려된다.
```

**해결의 3가지 제약 원칙**

| 원칙 | 뜻 | 반대말 |
|------|------|--------|
| **① 가진 것으로 시작한다** | 있는 자원의 재배치·재조합이 1순위 | "예산이 있으면", "AI가 도와주면" |
| **② 작게 시작한다** | 우리 반 · 우리 학교 규모로 시제품 검증 | 전국 확산 · 앱 스토어 출시 |
| **③ 대체 가능성으로 판단** | "이것 없이도 가능한가"를 먼저 묻는다 | 화려한 도구가 있어야 성립하는 안 |

> **예산 · 시간 · 사람이 늘어난다면 무엇이 달라지는가**는 별도로 기록해둔다.
> 이것이 학교·기관에 제안할 때의 **확장 시나리오**가 된다.
> 하지만 **1차 시제품은 반드시 지금 자원 안에서** 만든다.

### 이 단계에서 하는 일

#### ① 해결 트랙 4개 중 하나 선택

| 트랙 | 무엇을 만드나 | 걸리는 시간 |
|------|---------------|-------------|
| **T1. 조사 트랙** | 1차 데이터 (관찰·인터뷰·실측) | 2–4주 |
| **T2. 시제품 트랙** | 프로토타입 (앱·프린트물·서비스 시안) | 4–8주 |
| **T3. 캠페인 트랙** | 사람들의 인식·행동을 바꾸는 콘텐츠 | 3–6주 |
| **T4. 제안 트랙** | 학교·기관에 제출하는 정책 제안서 | 4–8주 |

> **선택 기준**: 관심사와 CIP 축3(관찰↔개입) 결과에 따라 자동 추천되지만, 학생이 최종 결정.
> **4트랙 모두 "1차 데이터"가 필수다.** 검색으로만 채운 산출물은 반려된다.
> **4트랙 모두 자원 지도 안에서 실행 가능해야 한다.** 예산 없이도 시작할 수 있는 안이 우선순위.

#### ② 검증 — 반증 조건 확인

2단계에서 세운 반증 조건을 실제로 돌려본다.

- 데이터가 반증 조건에 걸린다 → **가설 폐기 · 폐기 이력 등록 · 1단계로 회귀**
- 데이터가 반증 조건을 통과한다 → **정식 결과물로 채택 · 5단위 공유로 진입**

**폐기는 실패가 아니라 성공적인 검증이다.** 죽은 가설의 기록이 관심사를 단단하게 만든다.

#### ③ 공유 5단위

만든 것을 어디까지 열지 학생이 정한다.

```
개인 → 그룹 → 학급 → 학교 → 공개
```

**공개까지 가야 완주가 아니다.** 개인 단위로만 남겨도 문제 포트폴리오에 등록된다.

### 이 단계에서 챙길 독서 목표

- **창조** — 읽은 것을 내 학교·동네·일상에 대입해 새로 만든다.
- **실천** — 손에 잡히는 산출물이 있어야 자기 관심사가 자기 것이 된다.

### 이 단계의 산출물

| 종류 | 예시 |
|------|------|
| **정식 결과물** | 시간표 재구성 실험 보고서 · 학생 피로도 앱 시안 · 교실 캠페인 |
| **폐기 이력** | "스마트폰이 원인이라는 가설은 로그 데이터로 반증됨. 배운 것: 눈에 잘 보이는 변수를 원인으로 착각" |
| **다음 질문** | 해결 과정에서 새로 발견된 관심사 (→ 1단계 재료) |

## 4. 세 단계를 한눈에

| 단계 | 핵심 질문 | 독서 목표 | 산출물 |
|------|-----------|-----------|--------|
| **1. 발견** | 무엇에 자꾸 걸려 넘어지나 | 재미 · 성찰 | 관심사 Top 3 · 억울했던 규칙 1건 |
| **2. 질문** | 이건 정말 문제인가 | 비판 · 통합 · 공감 | 문제 정의서 (금지된 답 · 반증 조건 · 반대편) |
| **3. 해결** | 그래서 나는 무엇을 만드나 (가진 자원으로) | 창조 · 실천 | 시제품 · 조사 보고서 · 폐기 이력 |

---

## 5. 무엇을 재는가

리딩크루는 다음을 **재지 않는다.**

- ❌ 완독 권수 · 독서 시간 · 감상문의 감정적 풍부함

리딩크루가 **재는 것.**

- ✅ **금지된 답의 수** — 첫 생각을 몇 개 봉인했는가
- ✅ **반증 조건의 구체성** — "내가 틀리면 무엇이 관찰되는가"를 관찰 가능하게 썼는가
- ✅ **반대편 대변인 발언의 정확도** — 상대의 언어로 상대의 논리를 재현했는가
- ✅ **폐기 이력의 서술 질** — 무엇 때문에 죽였는지, 무엇을 배웠는지
- ✅ **1차 데이터의 유무** — 검색이 아닌 관찰·인터뷰·실측을 했는가
- ✅ **자원 정합성** — 해결책이 실제로 가진 자원 안에서 굴러갔는가 ("있다면" 아닌 "있는 것으로")

---

## 6. 마무리 — 한 문장

> **질문에서 시작해서 해결에서 끝난다.
> 해결이 실패하면 새 질문이 되고, 새 질문은 다시 해결을 부른다.
> 이 순환이 멈추지 않는 사람 —
> 그가 리딩크루가 기르려는 독자다.**
